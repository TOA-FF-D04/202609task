# SimpleAI

依存ライブラリなしで動く、学習用の小さな日本語チャットボットです。

## できること

- あいさつに返事する
- 名前を覚える
- 現在時刻を答える
- 入力に近い話題を推測して返事する

## 実行方法

Python 3.10 以降を用意したあと、PowerShell で次を実行します。

```powershell
python chatbot.py
```

終了するには `終了` と入力します。名前を覚えさせるには、たとえば `私の名前はさくら` と入力します。

## テスト

```powershell
python -m unittest -v
```

これは ChatGPT のような大規模言語モデルではなく、入力のキーワードと簡単な文字列比較で返答を選ぶ仕組みです。次の段階では、返答データを増やす、Web 画面を付ける、外部 AI API に接続する、といった拡張ができます。
